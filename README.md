# 삼성한우리합창단 · HEAR WE GO!

제21회 정기연주회 홍보용 한국어 반응형 정적 웹사이트입니다. 제공된 2026년 공연 포스터의 색상, 공연 정보, 프로그램과 교통 안내를 반영했습니다.

## 실행

```sh
cd /workspace/hwr2026
python -m http.server 3000 --bind 0.0.0.0
```

별도 설치나 빌드는 필요 없습니다. `index.html`은 공연 정보, `style.css`는 디자인, `script.js`는 카카오톡 채널명 복사를 담당합니다. 폰트 로딩 전에는 시스템 글꼴을 사용합니다.

공식 예매 링크와 입장권 신청 방법은 미제공 상태입니다. 제공된 Illustrator 파일을 변환한 공식 SVG 앞·뒷면을 `assets/`에 포함합니다. 글자와 도형은 벡터이며 뒷면의 단체 사진은 래스터 이미지입니다. 프로그램의 01~03 표시는 곡 목록의 시각적 구분입니다.

## GitHub Pages 배포

GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
`main` 브랜치에 변경 사항을 push하면 `.github/workflows/pages.yml`이 웹사이트 파일만 배포합니다.
첫 배포가 성공한 뒤 기본 주소는 `https://arterica5.github.io/hwr2026/`입니다.
Actions 탭에서 실행 결과와 배포 주소를 확인할 수 있습니다.

## 글꼴
기본 글꼴은 Pretendard Variable v1.3.9입니다. 공식 프로젝트의 SIL Open Font License 파일과 웹폰트를 `assets/fonts/`에 자체 호스팅하며, 제목·메뉴·본문 모두 동일하게 적용합니다. 폰트 로딩 전에는 시스템 sans-serif 글꼴로 표시됩니다.

## 모바일 디자인 기준
QR 방문자를 우선합니다. 첫 화면에 일시·장소·네이버 지도를 노출하고, 웹페이지 텍스트는 16px 이상, 주요 버튼은 높이 48px 이상으로 유지합니다. 불필요한 영문 레이블과 장식 번호를 추가하지 않습니다. 포스터 원본 내부의 글자는 SVG 아트워크의 일부입니다.

## 타이포그래피와 정렬
- Pretendard 단일 폰트, 본문 16px/400. 헤더 보조 문구만 요청에 따라 14px.
- 섹션 제목은 모바일 34px, PC 48px/650. 이름은 26px·30px, 리드 문구는 22px·24px.
- 제목 #1d1d1f, 본문 #424245, 보조 정보 #6e6e73. 파란색은 원본 아트워크·링크·주요 버튼에 사용.
- 모든 본문 섹션은 같은 최대 너비와 좌우 패딩을 공유하고, 모바일은 왼쪽 정렬을 기준으로 함.

## 제목 글꼴과 포스터 모션
사용자가 제공한 Samsung Sharp Sans WOFF(400·500·700)를 제목에 자체 호스팅합니다. 한글 글리프는 없어 한글 제목과 본문은 Pretendard로 표시됩니다. 원본 포스터의 글자는 벡터 윤곽선이므로 그대로 유지합니다.
첫 포스터는 로고·슬로건·음파·일시와 장소가 약 1.35초에 걸쳐 한 번 등장하는 SVG입니다. 모션 줄이기 설정에서는 애니메이션 없이 전체가 즉시 보입니다. 정적 원본 `assets/leaflet-front.svg`도 보존합니다.

## 모바일 티켓
`assets/mobile-ticket.jpg`는 사용자가 제공한 ZIP의 원본 JPG를 변환 없이 저장한 파일입니다. 사이트에서 다운로드하거나 원본을 새 창으로 열어 저장할 수 있습니다. 공연 당일 박스오피스에서 좌석권으로 교환합니다. 이메일이나 개인정보를 수집하지 않습니다.
